Quick Sort Passenger Sorting

Problem → Algorithm → Input → Processing → Output → Complexity

Problem

Arrange passengers according to a selected field so airport staff can quickly view a useful order.

Algorithm

Quick Sort uses divide and conquer. It selects a pivot, partitions the array and recursively sorts the two smaller parts.

Why here?

Priority boarding is a practical case: passengers can be arranged from highest priority to normal priority without using a built-in sorting function.

BestO(n log n)
AverageO(n log n)
WorstO(n²)
SpaceO(log n)*
*For the recursive implementation, average stack usage is O(log n); worst-case recursion can reach O(n).

Run Quick Sort

No Python or JavaScript built-in sorting is used.
