How Quick Sort is applied

1. Input

Passenger records with priority values.

2. Pivot

Select a record as the pivot.

3. Partition

Place smaller-priority values on one side and larger values on the other.

4. Recursion

Repeat for the two sub-arrays.

5. Output

Display the ordered passenger list and metrics.
